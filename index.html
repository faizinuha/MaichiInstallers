🚀 Cara Pakai Windows

1

Buka PowerShell as Administrator

Klik Start → cari "PowerShell" → klik kanan → "Run as Administrator"

2

Jalankan command di atas

Copy paste command dan tekan Enter. Script akan otomatis download dan jalan.

3

Pilih app yang mau diinstall

Pilih kategori → centang app yang mau di-install → konfirmasi → selesai! ☕
